# Rinne Recruitment HTML v1.2.2

解壓後開啟 index.html 為正式遊戲入口；review.html 為完整预覽與設定頁，兩者共用程式及設定。

## 這版修正

採用使用者附件分層動畫 v8：玩家右側的左手先於頭部、眼口及髮束繪製；收肘時重疊的手指被頭部遮住。指向時仍自動播放嘴型（無配音）。

v1.1 固定繪製 941×1672，再逐幀複製給輪廓光，而且時間差被限制為最多50ms；當渲染超過50ms時動畫時間落後真實時間，產生慢動作。v1.2 使用顯示尺寸及像素比決定人物與光暈畫布（寬度上限720），裁掉分層PNG的透明留白並保留原座標，預先計算腿部網格列並減少繪製切片；人物每個RAF可繪製一幀，不再固定降為30fps。動作按實際經過時間推進，隱藏／暫停續播時仍重設時鐘，避免補算離開時間。

白色呼吸輪廓光仍以同幀人物alpha產生，週期控制、原有進場／淡入、七張卡牌與按鈕反光保留。完整JSON仍含所有人物、文字、光效及介面設定，舊版設定可回用。匯入只改目前頁面；config.js 與 settings-defaults.json 為交付預設。

## 驗證與使用

Node.js tests/check_v1.cjs、tests/check_settings_v1.cjs 為狀態與JSON驗證。tests/check_rig_render.cjs 另需 @napi-rs/canvas，測實際Canvas渲染與輪廓alpha，非瀏覽器GPU測試。效能數據見 docs/performance.json，僅原生Canvas CPU基準，不包含瀏覽器SVG濾鏡、CSS合成或手機GPU；使用者裝置效能仍待實機驗收；FX13 的 Chromium 實際渲染驗證見下方。

來源附件：rinne-layered-motion (6).zip。既有美術與字型沿用原專案，字型授權見 LICENSE-font.txt。招募為前端示範，不含遊戲後端。v1.1 保留供回退。

## FX13–14 修正

反光與輪廓光改為獨立 WAAPI 控制器，重新啟用時檢查播放狀態；設定匯入後重新同步，輪廓光週期調整立即更新。試播反光完成後恢復原自動開關，舊試播取消不能啟動過期動畫。狀態欄明示總動效關閉、校準、活動切換、畫面不可見與系統減少動態等暫停原因；仍尊重這些設定，不強制改掉使用者參數。兩入口與單檔預覽共用新控制器。

JS／DOM 狀態及動畫控制器回歸已驗證。v1.2.2 補上 FX13 的真實瀏覽器渲染驗證。

## FX13 本機遮罩修正（v1.2.2）

在 Chromium 153 以 file:// 重現：三處 CSS mask-image 的外部 PNG 遭到 CORS 阻擋，即使播放狀態為啟用且亮帶 opacity=0.7，反光仍完全透明。已將這三張遮罩以 data:image/png 內嵌於 CSS，讓雙擊離線開啟可用。未關閉瀏覽器安全檢查，原按鈕與美術字保持不變。

使用真正 Chromium 153 檢查正式頁、設定預覽頁與單檔預覽：確認無遮罩載入錯誤，並比較三處反光在暗／亮階段的實際截圖像素。這是 Linux headless Chromium 的渲染驗證，不代表所有瀏覽器或 Windows 實機效能均已驗證。

單檔預覽另修正了動態建立的七張懸浮卡牌 URL，全部內嵌，不需依賴旁邊的 assets 資料夾。
